1. RINGKASAN EKSEKUTIF PROJEK (EXECUTIVE SUMMARY)
--------------------------------------------------------------------------------
- NAMA PROJEK: ByteRead
- TAGLINE: "Level Up Literasimu. Baca Byte-nya, Menangkan Gamenya."
- KATEGORI: Gamified Academic Library & Byte-Sized Tech Learning Platform.
- TARGET AUDIENS: Mahasiswa IT/Komputer, Siswa SMK Rekayasa Perangkat Lunak (RPL), Junior Developer, & Gen-Z Tech Enthusiasts.
- MASALAH UTAMA:
  1. Siswa/mahasiswa IT malas membaca buku teks tebal tradisional yang kaku dan membosankan.
  2. Merasa terintimidasi/insecure dengan materi teori yang terlalu akademis.
  3. Pengguna lebih terbiasa membaca dokumentasi API pendek, artikel Medium, dan menyukai meme programmer.
  4. Rendahnya retensi membaca di perpustakaan sekolah/kampus akibat ketiadaan insentif langsung yang relevan.
- SOLUSI UTAMA (BYTEREAD):
  1. Platform membaca berbasis "Byte-Sized Reading" (dokumentasi API & flashcard style, dibaca < 3 menit).
  2. Linear 3-Step Guided User Flow: Read Byte Material ➔ Play Boss Fight Quiz (Quizizz Style + Meme IT) ➔ Win Rewards & Campus Rank.
  3. Insentif lokal nyata: Reward poin XP yang dapat ditukarkan langsung dengan "Voucher Special Nasi Ayam Laos Pak Yoyok 🍗" dan voucher kantin kampus.
  4. Sistem Liga Mingguan (Weekly Season Competition) dengan hadiah Juara #1 berupa makan gratis Nasi Ayam Laos Pak Yoyok 1 minggu penuh + Frame Mahkota Emas.

- Subjudul: Level Up Literasimu. Baca Byte-nya, Menangkan Gamenya.
